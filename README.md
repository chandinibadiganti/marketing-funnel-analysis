# Marketing Funnel & Conversion Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing marketing funnel data to identify customer conversion drop-offs, evaluate channel performance, and provide actionable recommendations to improve lead-to-customer conversion rates.

The analysis was performed using Tableau with the Bank Marketing Dataset.

---

## 🎯 Objectives

* Analyze customer conversion behavior
* Identify major drop-off points in the funnel
* Compare communication channel performance
* Study campaign effectiveness
* Generate business insights for improving conversions

---

## 🛠️ Tools Used

* Tableau Public
* CSV Dataset
* Data Visualization
* Funnel Analysis

---

## 📂 Dataset Used

Dataset: Bank Marketing Dataset

Source:

```text id="s1q8pk"
https://archive.ics.uci.edu/dataset/222/bank+marketing
```

The dataset contains customer demographic details, marketing campaign interactions, and conversion outcomes.

---

## 📊 Dashboard Components

### 1. Conversion Distribution

Shows the number of customers who converted and those who did not convert.

### 2. Channel Performance

Analyzes conversion performance across communication channels such as:

* Cellular
* Telephone
* Unknown

### 3. Campaign Analysis

Examines how repeated marketing campaigns impacted customer conversion.

### 4. Age Analysis

Studies customer conversion behavior across different age groups.

### 5. Key Insights Section

Summarizes major findings and recommendations from the analysis.

---

## 🔍 Key Insights

* Most customers did not convert.
* Cellular communication performed better than telephone communication.
* Repeated campaigns reduced conversion effectiveness.
* Certain age groups showed better conversion rates.

---

## ✅ Recommendations

* Focus more on cellular communication channels.
* Reduce excessive repeated marketing contacts.
* Create targeted campaigns for high-converting age groups.
* Improve customer engagement strategies at early funnel stages.
